Додај на почетен екран

На iPhone или iPad: допри копчето Share (квадрат со стрелка нагоре), па избери Add to Home Screen / Додај на почетен екран.

Инсталирај апликација

На Chrome или Edge: мени (⋮) → Install app / Инсталирај апликација или Add to Home screen.

На Android целосната „инсталација“ прави мала апликација (WebAPK) преку Chrome. Ако пишува блокирано или инсталацијата не оди: отвори Поставки → Апликации → Специјален пристап (или „Напредни“) → Инсталирај непознати апликации / Install unknown apps → избери Chrome → вклучи Дозволи. Потоа пробај пак од Chrome (не од Instagram/Facebook).

Ако сè уште не дозволува: во Chrome мени (⋮) користи Add to Home screen / Додај на почетен екран — добиваш икона без целосна WebAPK инсталација. Ажурирај Chrome и Android System WebView од Play Store.

Ако Play Protect пишува дека апликацијата е за „постара верзија на Android“ или нема најнови приватносни заштити: тоа е од малиот пакет (WebAPK) што Chrome го прави за веб-апликации, не од Play Store и не е грешка на сајтот. Ако му веруваш на изворот, избери Инсталирај сепак / Install anyway.
